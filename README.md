## 🐒 1. Ambil Project (CLONE)

Buka **CMD / Terminal**, lalu copy ini:

    git clone https://github.com/MAYcode96/GameProject.git


cd GameProject


## 🐒 2. Buka di Unity

* Buka **Unity Hub**
* Klik **Add**
* Pilih folder **GameProject**
* Klik **Open**

SELESAI ✅

---
